# 🎸 Cliffs of Dover — Guitar Explorer

Un catálogo musical interactivo dedicado a los mejores riffs, solos y leyendas de la guitarra eléctrica. Inspirado en la icónica pieza instrumental de Eric Johnson.

![Estado](https://img.shields.io/badge/Estado-Terminado-success)

![Vite](https://img.shields.io/badge/Vite-6-purple)
![Tailwind](https://img.shields.io/badge/Tailwind-4-cyan)
![Zustand](https://img.shields.io/badge/Zustand-5-orange)

---

## 🎯 Características

- **Catálogo interactivo:** Explora las canciones con tarjetas de diseño moderno.
- **Reproductor persistente:** Barra de reproducción inferior con controles de Play, Pausa, Siguiente y Anterior.
- **Buscador en tiempo real:** Filtra por título, artista o álbum.
- **Sistema de favoritos (Playlist):** Añade o quita canciones de tu lista personalizada.
- **Diseño responsivo:** Interfaz oscura inspirada en amplificadores de válvulas y equipos de sonido.
- **Estado global:** Gestión eficiente con Zustand.

## 🛠 Tecnologías

- **React 18** — Librería de UI.
- **Vite** — Empaquetador y servidor de desarrollo.
- **React Router** — Navegación entre vistas.
- **Tailwind CSS v4** — Estilizado.
- **Zustand** — Estado global.
- **Lucide React** — Iconos.
